# Long Roast: Lawmakers and the File They Cannot Convert

A single-sentence satirical roast for the make.fun bounty
`u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7`.

## Concept

The lawmakers in this roast spent three years writing and passing a bill that
regulates a document format — and the bill itself circulates in a format nobody
in their own building can open. The law that governs the format is trapped by
the format: the authority builds up through the long drafting effort, then
collapses on the one file that matters, and the punch lands in the final words,
when the bill turns out to be unopenable, let alone convertible to PDF.

## Run

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (UTF-8, no trailing newline).

## Determinism

The program is fully deterministic: the same single sentence is written on
every run, with no network access and no dependencies — only Node's built-in
`node:fs` module.
